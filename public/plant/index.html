What it does

  • Reads soil moisture at bottom, middle, and top zones of the pot/root ball.
  • Classifies under-hydrated / OK / over-hydrated per zone and overall.
  • App camera: identify plant species/cultivar class, then recommend water, nutrients/food, or both.
  • Push/local alerts when a zone stays dry or waterlogged beyond thresholds.

How it works (system)

  1. Three capacitive (or resistive DIY) sensing pads spaced along a stake / ring / mat.
  2. MCU (ESP32-C3) samples ADC, filters noise, estimates volumetric moisture proxy.
  3. BLE/Wi‑Fi sends readings to phone app every N seconds.
  4. App runs on-device or cloud plant ID from a photo (start with a known plant list + PlantNet/Pl@ntNet-style API or TensorFlow Lite model).
  5. Rules engine merges species watering profile + 3-zone state → action card.
Do not use bare copper resistive probes for long-term — they corrode and poison soil. Prefer capacitive sensors with conformal coating / food-safe epoxy.

Step-by-step home build (Template A)

  1. Print the stake — Open cad/plant_sense_A_stake.scad in OpenSCAD → F6 Render → Export STL. Slice in PETG, 0.2mm, 4 walls, 25% infill, upright. Print lid separately.
  2. Install heat-set inserts — M2 inserts in lid bosses with soldering iron tip (~200°C). Do not melt through walls.
  3. Prepare three sensor pads — If using modules: remove analog-out boards from cheap sticks, extend wires to pad positions at 30mm / 90mm / 150mm from tip. Or etch copper tape pads on PETG + coat.
  4. Waterproof — Conformal coat electronics; epoxy only the soil-facing pad edges. Cure 24h.
  5. Wire ESP32 — Pads → ADC1 channels (use attenuator-safe pins). Battery → TP4056 → 3V3. Common ground.
  6. Flash firmware — PlatformIO: select ESP32-C3, upload main.cpp. Serial monitor should print Top/Mid/Bot values.
  7. Calibrate — Dry air reading = 0% proxy; soaked sponge = 100% proxy. Store in NVS.
  8. Assemble — Cable-tie battery in cavity, lid with M2 screws, leave USB access or charge pogo.
  9. App — Install Expo Go test app or build APK. Pair BLE, take plant photo, confirm recommendation card.
  10. Document PoC — Photo of device in soil + phone screenshot. This is your Kickstarter / patent appendix evidence.
