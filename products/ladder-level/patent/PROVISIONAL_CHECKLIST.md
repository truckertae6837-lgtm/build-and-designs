# US Provisional Patent Checklist — ladder level

1. [ ] Finalize inventor disclosure + drawings
2. [ ] Confirm inventor inventorship (who contributed to conception)
3. [ ] Decide entity size (micro entity?)
4. [ ] Create USPTO.gov account / hire registered attorney
5. [ ] File provisional with written description enabling a skilled person to make/use
6. [ ] Docket 12-month deadline for non-provisional / PCT
7. [ ] Avoid public sale/disclosure before filing if possible
8. [ ] Keep lab notebook dated evidence of conception/reduction to practice

**This pack is not a filed patent.** Filing fees and attorney fees are separate.
